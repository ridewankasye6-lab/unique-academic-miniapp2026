📘 CHAPTER FOUR: MEMORY AND FORGETTING

Meaning, Processes, Stages, Factors, Theories of Forgetting & Memory Improvement

🔑 5.1 Memory

🔑 Meaning and Processes of Memory

  • Memory is the retention of information learned earlier over time.
    🧠 Think of memory as your brain's way of saving information so you can use it later.
  • It is the way in which we record the past for later use in the present.
    🔄 Example: Remembering the steps to solve a math problem you learned last week.
  • Memory is a blanket label for a large number of processes that form the bridges between our past and our present experiences.
    🌉 It connects what you experienced before to what you do now.

🧩 Processes of Memory

Memory involves the mental activities we perform to put information into memory (so we don't forget), keep it stored, and make use of it later when needed:

  • a) Encoding: Refers to the form (i.e. the code) in which an item of information is to be recorded/placed in memory. In encoding, we transform a sensory input into a form or a memory code that can be further processed.
  • b) Storage: It is the location in the memory system in which material is saved. Storage is the persistence of information in memory.
  • c) Retrieval: Is the point at which one tries to remember a particular information (brought into awareness and used) from among all the others we have stored.

🧠 5.1.2 Stages / Structure of Memory

  • Memory structure refers to how information is represented in memory, how long it lasts, and how it is organized.
  • Many cognitive psychologists relate the mind to a digital computer that takes items of information in processes or in stages, and then produces an output.
  • Models of memory based on this idea are Information processing models/theories.
  • Like a computer, we also store vast amounts of information in our memory storehouse. From this storehouse, we can retrieve some information onto a limited capacity of working memory (consciousness).
According to Atkinson and Shiffrin (1968), memory is structured into three main parts/stores that differ in function, capacity, and duration:
  1. Sensory Memory (Sensory Register)
  2. Short-Term Memory
  3. Long-Term Memory

1️⃣ Sensory Memory / Sensory Register

🔑 What is Sensory Memory?

  • It is the entryway to memory — the very first place where incoming information is briefly stored (until we select it for attention).
  • Think of it as a holding bin that keeps information until you decide what's important to pay attention to.
  • It gives your brain a short moment to decide whether information is important or just noise.
  • Sensory memory holds virtually all the information reaching our senses for a brief time:
    • 👁️ Visual images (Iconic memory): Visual images stay in sensory memory / the visual system for a maximum of about 1 second.
    • 👂 Auditory images (Echoic memory): Auditory images remain in the auditory system for a slightly longer time, by most estimates up to 2 seconds or so.
  • The information stored in sensory memory is a fairly accurate representation of the environmental information but unprocessed.
  • Most information briefly held in sensory memory simply decays from the register. Those pieces of information that receive attention and recognition pass on to short-term memory for further processing.

2️⃣ Short-Term Memory (STM)

Short-term memory is part of our memory that holds the contents of our attention.

  • Unlike sensory memories, short-term memories are not brief replicas of the environmental message. Instead, they consist of the by-products or end results of perceptual analysis.
  • STM is important in a variety of tasks such as thinking, reading, speaking, and problem solving.
  • Various terms used to refer to this stage of memory include: working memory, immediate memory, active memory, and primary memory.

📌 Short-term memory is distinguished by four characteristics:

  • It is active: Information remains in STM only so long as the person is consciously processing, examining, or manipulating it. People use STM as a "workspace" to process new information and to call up relevant information from LTM.
  • Rapid accessibility: Information in STM is readily available for use. The difference between STM and LTM is the difference between searching for information in an open computer file versus a file stored on the hard drive.
  • Preserves the temporal sequence of information: STM usually helps us to maintain the information in sequential manner for a temporary period. It keeps information fresh until it goes to further analysis and is stored in LTM in a meaningful way.
  • Limited capacity: The number of items that short-term memory can handle at any one time is small — about "7 plus or minus 2" pieces of information at a time (Miller, 1956).

💡 Overcoming Capacity Limits & Prolonging STM

  • Chunking: According to most models of memory, we overcome capacity limits by grouping small groups of information into larger units or chunks. Chunking is the grouping or "packing" of information into higher order units that can be remembered as single units. It expands working memory by making large amounts of information more manageable. A chunk may be a word, a phrase, a sentence, or even a visual image, depending on previous experience.
  • Duration: STM holds information (sounds, visual images, words, sentences, etc.) received from sensory memory for up to about 30 seconds by most estimates.
  • Maintenance Rehearsal: Repeating information silently to prolong its presence in STM. Material in STM is easily displaced unless we do something to keep it there.
  • Elaborative Rehearsal: Links new information with existing memories and knowledge in LTM.

3️⃣ Long-Term Memory (LTM)

It is a relatively permanent storage of meaningful information. The capacity of LTM seems to have no practical limits. The LTM is assumed to be composed of different subsystems:

  • Declarative / Explicit Memory: The conscious recollection of information such as specific facts or events that can be verbally communicated. Declarative memory is subdivided into:
    • Semantic memory: Memories of meaning of words, concepts, and our knowledge of the world, independent of any particular context.
    • Episodic memory: Memories of events and situations.
  • Non-declarative / Implicit Memory: Refers to memory without awareness; memory that affects behavior but cannot consciously be recalled. One of the most important kinds of implicit memory is procedural memory (habitual responses).
🌐 Semantic Networks: A complex web of semantic associations that link items in memory such that retrieving one item triggers the retrieval of others as well.

📊 Serial Position Effect

If you are shown a list of items and are then asked immediately to recall them, your retention of any particular item will depend on its position in the list.

  • Primacy Effect: Recall will be best for items at the beginning of the list.
  • Recency Effect: Recall will be best for items at the end of the list.
  • When retention of all items is plotted, the result will be a U-shaped curve.
  • Why it happens: According to the Serial Position Effect or the three-box model, the first few items are remembered well because STM was relatively "empty" when they entered. The last few items are remembered because at the time of recall, they are still sitting in STM. Middle items drop out because STM gets crowded before they can be stored in LTM.

📈 5.1.3 Factors Affecting Memory

Memory retention can vary greatly from person to person, and many factors influence how well we learn, store, and recall information. Memory includes learning, retention, and remembering, which are all vital for good memory capability.

11 Major Factors That Influence Memory Process:

  • ✅ 1. Ability to Retain / Past Experience
    • A good memory depends on the strength of memory traces left in the brain by past experiences.
    • Stronger memory traces = better recall.
    💡 Example: If you practice solving math problems multiple times, the strong traces help you remember the steps easily later.
  • ✅ 2. Good Health
    • Physical and mental health play a major role in memory.
    • A healthy brain can retain learned material better than an unhealthy one.
    💡 Example: Proper diet, regular exercise, and hydration improve brain function and memory.
  • ✅ 3. Age of the Learner
    • Younger individuals generally remember better than the aged.
    • As we grow older, memory capacity may decline due to brain aging.
    💡 Example: A 15-year-old can memorize a new poem faster than an 80-year-old.
  • ✅ 4. Maturity: Higher mental maturity allows better conceptual organization and understanding.
  • ✅ 5. Will to Remember: Conscious motivation and willingness to retain information greatly improve memory performance.
  • ✅ 6. Intelligence: Higher cognitive and reasoning ability facilitates faster encoding and retrieval.
  • ✅ 7. Interest: Genuine interest in a subject enhances focus and memory retention.
  • ✅ 8. Overlearning: Continuous practice and review even after mastering a material ensures long-term preservation.
  • ✅ 9. Speed of Learning: Fast learners often retain information effectively when paired with proper understanding.
  • ✅ 10. Meaningfulness of the Material: Meaningful and well-structured material is far easier to store than abstract or random facts.
  • ✅ 11. Sleep or Rest: Adequate sleep prevents interference and consolidates memory traces in the brain.

📉 5.2 Forgetting

5.2.1 Meaning and Concepts of Forgetting

  • In our daily living, we encounter so much information. If we attempt to encode, store & recall all information, we would be in trouble.
  • Hence, we are selective in storing and forgetting information. Sometimes we are motivated to forget something and recall what we want to remember. Psychologists call this phenomenon motivated forgetting.
  • Psychologists generally use the term forgetting to refer to the apparent loss of information already encoded and stored in long-term memory.
  • Hermann Ebbinghaus (1885): First began to study forgetting using nonsense syllables (three-letter combinations that look like words but are meaningless, e.g., ROH, KUF).
  • The Forgetting Curve: According to Ebbinghaus, the most rapid forgetting occurs in the first hours, and particularly in the first hour of learning. After nine hours, the rate of forgetting slows down.
  • Furthermore, relearning of previously mastered material is almost always faster than starting from scratch.

🔍 5.2.2 Theories of Forgetting

Psychologists have identified five primary mechanisms/theories of forgetting:

  • 1. The Decay Theory: Memory traces or engrams fade with time if they are not accessed now and then. In decay, the trace simply fades away with nothing left behind purely because of the passage of time.
  • 2. Interference Theory: Forgetting occurs because similar items of information interfere with one another in either storage or retrieval.
    • Proactive Interference: Information learned earlier interferes with the recall of newer material (Old interferes with New).
    • Retroactive Interference: New information interferes with the ability to remember old information (New interferes with Old).
  • 3. Displacement Theory (New Memory for Old): Holds that new information entering memory can wipe out old information. This works specifically for STM where capacity is limited to 7 ± 2 chunks. It does not apply to LTM, which has virtually unlimited capacity.
  • 4. Motivated Forgetting: According to Freud, this is the blocking of memories from consciousness that are too threatening or painful to live with, a self-protective process he called Repression. Today, psychologists use the broader term motivated forgetting.
  • 5. Cue-Dependent Forgetting: Refers to forgetting due to a lack of retrieval cues, where we feel as if we have lost the call number for an entry in the mind's library.
    🏠 Context Effects: This explains why remembering is often easier when you are in the same physical environment as you were when the event occurred.

🚀 5.3 Improving Memory

Some simple mnemonics/memory aids are useful, but complicated ones are often more bothersome than beneficial. A better approach is to follow these evidence-based guidelines:

  • 🎯 Pay Attention: We often fail to remember simply because we never encoded the information in the first place.
  • 💡 Encode information in more than one way / Add meaning: The more elaborated (meaningful) the material, the more likely it is to link up with information already in long-term memory.
  • ⏳ Take your time: Minimize interference by using study breaks for rest. Sleep is the ultimate way to reduce interference.
  • 🔄 Overlearn / Practice: Study information even after you think you already know it to solidify memory traces.
  • 📖 Monitor your learning (SQ3R): Test yourself frequently, rehearse thoroughly, and review periodically to assess your true level of mastery.
  • ⛏️ Increase the Depth of Processing: Think deeply about the concepts rather than skimming surface details.
  • 🌴 Hierarchical Organization: Structure information into clear categories, subcategories, and outlines.
  • 🔤 Verbal Mnemonics: Use acronyms, rhymes, or acrostics to anchor ordered lists.
  • 🏛️ Method of Loci: Associate items you want to remember with specific physical locations in a familiar room or path.
  • 📌 Peg-Word Method: Link numbers with peg words (e.g., "one is a bun") to memorize ordered lists.
  • 🛡️ Minimize Interference: Avoid studying similar subjects back-to-back without breaks.
  • 🏞️ Utilize Context Effects: Recreate or leverage environmental cues present during initial learning.
