CHAPTER 4 MEMORY AND FORGETTING

በዚህምዕራፍ ስር እንግዲህ የማስታወስ ችግር ያለባችሁምናምን ትፈወሳላችሁ፤ በደንብ አንብባችሁ ተግባራዊ ብታደርጉት በጣምይጠቅሟቸዋል።

Meaning and Processes of Memory

Memory is the retention of information/what is learned earlier over time. It is the way in which we record the past for later use in the present.

Memory ማለት እንደምታውቁት "ትውስታ" እንደማለት ነው። ትውስታ ማለትስ ምን ማለት ነው? ከላይ ያለውን ደግማችሁ አንብቡት!

አሁን ቀጥለን ስለ Memory Processኦች እና ስለ Memory Structure እናያለን።

The processes of Memory: Are the mental activities we perform to put information into memory, to keep it there, and to make use of it later. አብዛኛውን ጊዜ ሳይኮሎጂስቶች የMemoryን ተፈጥሮ ከኮምፒውተር ጋር አያይዘው ያዩታል። ሶስቱ የMemory ሂደቶች፤ አንድ ነገር ለማስታወስ ነገሩ በሚከተሉት ሂደት ውስጥ ያልፋል።

1. Encoding: In encoding we transform a sensory input into a form or a memory code that can be further processed. ይሄ ከውጪየመጣው Information/መረጃ ቀጥታ ወደ አይምሮ ሄዶ Useable በሆነ form (ለመጠቀም አመቺ በሆነ መንገድ) የሚቀመጥበት ነው።

2. Storage: Is a location in memory system in which material is saved. Storage is the persistence of information in memory. ይሄ ደግሞ encode የተደረገው Information/መረጃ የሚቆይበት የአይምሮ ክፍል ነው።

3. Retrieval: This is the point at which the material in memory storage is located, brought into awareness and used. ይሄ Stored የሆነውን information/መረጃ አስታውሰን፣ የምንጠቀምበት የመጨረሻው ሂደት ነው።

ስለዚህ በቀላሉ Memoryን እንዲህ ማብራራት እንችላለን።

"Memory is the process by which information is encoded (phase1), stored (phase 2) and later retrieved (phase 3)."

Structure of Memory

Memory structure is the nature of memory storage itself- how information:

  • Is represented in memory
  • How long it lasts
  • How it is organized

ያው እኛ በተለምዶ memoryን ወይምማስታወስን ቀለል አድርገን እናዩዋለን እንጂMemory structure ትንሽ ከበድ ይላል፣ እነዚህን ከላይ የተዘረዘሩ ሶስት ነገሮችን ያጠቃልላል።

Like computer, we also store vast amounts of information in our memory storehouse. ከstorehouseኡ አውጥተን ነው እንግዲህ "Mental screen" ላይ display የምናደርገው [የምናሳየው]። ማለትም ነገሩን በ ህሊናችን እናውቀዋለን። በእንደዚህ አይነት መልኩ ብዙ የmemory structure ሞዴሎች ተመስርቷል።

One of the most important and influential of these is the one developed by Richard Atkinson and Richard Shiffrin (1968). According to Atkinson and Shiffrin, memory has three structures.

1) Sensory Memory

It is the entry way to memory. It is the first information storage area.

  • እዚህጋ አንድ ያያቹት (Iconic Memory) ነገር storage ውስጥ የሚቆየውቢበዛ ለአንድ በሰከንድ ነው።
  • የሰማችሁት ነገር (Echonic memory) ደግሞቢበዛ ለሁለት ሰከንድ storageኡ ውስጥይቆያል።

ስለዚህ በSensory memory ውስጥ save ያደረግነው ነገር ብዙ አይቆይም ነገር ግን attention ከሰጠነው ትንሽ ይቆያል [ማለትምወደ 2ተኛው memory/storage ይተላለፋል]

2) Short-term Memory: is part of our memory that holds the contents of our attention.

STM is important in a variety of tasks such as thinking, reading, speaking, and problem solving. አያችሁ የዚህ Memory ጥቅሙከመጀመሪያው የተሻለ ነው። ለምሳሌ ስታስቡ፣ ስታነቡ፣ ስታወሩ ምናምንinformationኡ Save የሚሆነው በዚህ Memory ውስጥ ነው። ይሄ ሚሞሪ ሌሎች የተለያዩ ስሞች አሉት።

  • Working memory
  • Immediate memory
  • Active memory
  • Primary memory

STM is distinguished by four characteristics

  • It is active - Information remains in STM only so long as the person is consciously processing, examining, or manipulating it. ይሄ "Active" ነውማለትም እንደ sensory memory ለአንድ ወይምሁለት ሰከንድ ብቻ አይደለም የሚቆየው። ያ ሰውመረጃውን በአይምሮው እያብሰለሰለ እስከ ቆየበት ጊዜ ድረስ መረጃው በአይምሮው (STM) ውስጥሊቆይ ይችላል።
  • Rapid accessibility - Information in STM is readily available for use. በውስጣችሁ ያለውን መረጃ ቶሎ አውጥታችሁ ወይም አስታውሳችሁ መጠቀም/መናገር ትችላላችሁ፤ ይሄ ከ "Long Term Memory" የተሻለ ያደርገዋል።
  • Preserves the temporal - mean that STM keeps the information fresh until it goes to further analysis and stored in LTM in meaningful way. ይሄኛው ባህሪ ደግሞ Store ያደረግነውመረጃ "Fresh ሆኖ" ወይምምንም ሳይነካ ሳንጠቀምበት ይቀመጣል ይላል።
  • Limited capacity - Short-term memory is a limited - capacity store that can maintain unrehearsed information up to 30 seconds. አያቹአ ይሄ ሚሞሪ በጣም ያልተለማመድነውወይምብዙ ትኩረት ያልሰጠነው ነገር እስከ 30 ሰከንድ በዚህ (STM) ውስጥሊቆይ ይችላል። Capacity: “The magic number” (George Miller)

Humans have the ability to retain 7 + -2 items of information (in adults). ይሄ George Miller የተባለው ሰውዬ አንድ ወጣት ሰው በውስጡከ5 እስከ 9 የሚጠጉ ነገሮችን የመያዝ አቅም አለውይላል።

People can group information in ways to expand their short-term memory capacity called “Chunking.” “Chunking” allows for easier encoding. እስኪ የሚከተለውን ምሳሌ እንመልከት 285566297488 ብዙ ጊዜእንዲህ አይነት ቁጥር ሲሰጠን ለመያዝ እንዲቀለን በchunking ዘዴ ከፋፍለን ነውምንይዘውማለትም 285 566 297 488 ልክ እንደዚህማለት ነው ለዚያም ነውብዙ ጊዜ አይታችሁ ከሆነ ስልክ ቁጥሮች እና የባንክ የአካውንት ቁጥሮች በዚህ መልክ የሚቀመጡት።

3) Long Term Memory

It is a memory system used for the relatively permanent storage of meaningful information. እስኪ እስካሁን ከአይምሮአችሁ ያልጠፋውን ወደፊትም probably ሊጠፋ የማይችል ብላችሁ የምታስቡት ነገር አስቡ፣ አአአዎ እሱ አሁን Stored የሆነው በLTMውስጥ ነው።

LTM stores information for indefinite periods. It may last for days, months, years, or even a lifetime.

ቀጥሎ ያሉትን በደንብ አንብቡ፥ እንድትረዱት ቀለል ባለ እንግሊዝኛ አስቀምጬላችዋለሁ።

The LTM is assumed to be composed of different sub systems.

  • Declarative/ explicit memory: The conscious recollection of information such as specific facts or events that can be verbally communicated. It is further subdivided into semantic and episodic memories.
    • Semantic memory: factual knowledge like the meaning of words, concepts and our ability to do math.
    • Episodic memory: is the memory of everyday events (such as times, location geography, associated emotions, and other contextual information) that can be explicitly stated or conjured. It is the collection of past personal experiences that occurred at particular times and places. ለምሳሌ ያለፈው አመት ልደታችሁ እንዴት እንደነበረ፣ ማን ማን እንደታደመ ስታስታዉሱ Episodic memory ይባላል።
  • Non-declarative/ implicit memory: One of the most important kinds of implicit memory is procedural memory. It is the "how to" knowledge of procedures or skills. ይሄን ከመጀመሪያው ለየት ሚያረገው፣ የመጀመሪያው (declarative) ለምሳሌ ስለ ፀጉር አቆራረጥ የተለያዩ መረጃ ስታገኝ እሱ declarative ስር ነውሚመደበው፥ ነገር ግን "ፀጉሬን እንዴት ልቆረጥ- ቅደም ተከተሉን" ካልን ከዚህኛው (implicit) memory ጋር ነው የሚያያዘው።

Serial Position Effect

Occurs when you are introduced to a lot of people at a party and find you can recall the names of the first few people you met and the last, but almost no one in between.

That is, recall will be best for items at the beginning of the list (the primacy effect) and at the end of the list (the recency effect). ይሄኛው ከላይ እንዳነበባችሁት፣ ለምሳሌ John Merry Kran Malin Dan እንዲህ አይነት ዝርዝር ስታዩ አብዛኛውን ጊዜምታስታውሱት የመጀመሪያውንና የመጨረሻውን ስም ነው፣ ይሄ ነው "serial position effect" ሚባለው።

Factors Affecting Memory

  • Ability to retain
  • Good health
  • Age of the learner
  • Maturity
  • Sleep or rest, and so on.

FORGETTING

Meaning and Concepts of Forgetting

በየለት ህይወታችን ብዙዎቻችን የተለያዩ ነገሮችን እንረሳለን፦ የሰው ስም፣ ሰዎች የነገሩን ነገር፣ ስልክ ቁጥር...ይሄ ስለምንድነው ካላችሁ? በየቀኑ ብዙ information encode, store እናረጋለን ይህንን ሁሉ ለማስታወስ ከፈለግን ችግር ውስጥ እንገባለን ስለዚህ we are selective in storing and forgetting information.

Psychologists generally use the term forgetting to refer to "the apparent loss of information already encoded and stored in the long-term memory." 'apparent' ማለት ግልፅ የሆነ እንደ ማለት ነው። አንድ ነገር ሙሉ በሙሉ ትዝ ሳይለን ሲቀር 'መርሳት' እንሏለን።

The first attempts to study forgetting were made by German psychologist Hermann Ebbinghaus. ይሄ ሰውዬ ስለforgetting ሲያጠና በራሱ ላይ ነበር Experiment የሰራው። ዝምብሎ እስኪ አስታውሳለሁ ወይስ እረሳለሁ የሚለውን check ለማድረግ ሶስት ፊደል ያላቸውን meaningless word ወሰደ እነሱም:- FIW እና BOZ እና he found that forgetting occurred systematically. ማለትም The most rapid forgetting occurs in the first hours, and particularly in the first hour. After nine hours, the rate of forgetting slows and declines little, even after the passage of many days. ሰው አንድን ነገር encode እና store ካረገ በኃላ ቶሎ ረሳ ከተባለ በ1ሰዓት ውስጥ ነውሚረሳው፣ ነገር ግን ከ9ሰዓት በኃላ የforgetting rateኡ ይቀንሳል።

Theories of Forgetting

Psychologists have proposed five mechanisms to account for forgetting.

1. The Decay Theory

The decay theory holds that memory traces or engram fade with time if they are not accessed now and then. ይሄ Theory ከስሙእንደምትረዱት "አንድን ነገር ደግመን ደጋግመን ትኩረት ካልሰጠነው፣ #በጊዜ ሂደት ሊረሳ ይችላል። indirectly በአይምሮአችን ውስጥ ያለው Physical የሆነው (Engram/trace) መልኩን መልቀቀ ወይም fade ማረግ ሲጀምር ነው Forgetting የሚከሰተውብሎ ነው የሚያምነውይሄ Theory.

ግን ሰው የሚረሳው ከጊዜ የተነሳ ብቻ አይደለም፣ ሰው አንድ ነገር በተለያየ መንገድ/ምክንያት ሊረሳ ይችላል።

2. Interference

is an explanation for forgetting in long term memory, which states that forgetting occurs because memories interfere with and disrupt one another, in other words forgetting occurs because of interference from other memories.

አያቹ አ ይሄ ደግሞ የሚለው ሰው የሚረሳው ቀድሞ በውስጡ የነበረውና አዲስ Encode ያደረገው ነገር እርስ በእርስ ሲገጩበት ነው።

There are two ways in which interference can cause forgetting: For Eg. When old phone numbers confuse with the new ones.

  • Proactive interference: Occurs when you cannot learn a new task because of an old task that had been learnt. When what we already know interferes with what we are currently learning ‒ where old memories disrupt new memories. I think እንግሊዘኛው በጣምግልፅ ነው።
  • Retroactive interference: Occurs when you forget a previously learnt task due to the learning of a new task. In other words, later learning interferes with earlier learning - where new memories disrupt old memories. ይሄም የገባችሁ ይመስለኛል።

3. Displacement Theory

This Theory Holds that new information entering memory can wipe out old information. ይሄ ደግሞ ሰው እንዴት ነውሚረሳው ለሚለውመልሱ "አዲስ የገባውመረጃ ቀድሞ የነበረውን ሲተካው ነው።" ብሎ ነው። አይምሮውብዙ ነገር በአንድ ጊዜመያዝ ስለማይችል እየተተካካ ነውመሄድ ያለበት ይላል። ይላል ይሄ theory እና This theory is mostly associated with the STM [Short Term Memory]..LTM ከሆነ ስህተት ነውምክንያቱም የLTM Capacity Unlimited ነው፤ Unlimited ከሆነ ደግሞ replacemet ሚባል ነገር የለም።

4. Motivated Forgetting

Is what Freud referred to as repressing memories. According to Freud, there are times when an event or an action is so painful that we can't deal with the memory of it, so we repress the memory completely.

ይሄ ማለት ደግሞማስታወስ ያልፈለጋቹት ነገር በውስጣችሁ አምቃችሁ(repress) በመያዝ በራሳችሁ ፍላጎት ነገሩን ልትረሱ ትችላላችሁ። Freud ይሄንን self-protective process Repression ብሎ ይጠራዋል። ለምሳሌ እኔ አሁን Mosheን እርሱት Moshe የሚለውን ስም ለመርሳት ማድረግ ያለባችሁን ሁሉ አድርጉና እርሱት ብዬ የቤት ስራ ብስጣችሁና ነገ በዚህ ሰዓት ከረሳችሁት ይሄ Motivated Forgetting ይባላል።

5. Cue Dependent Forgetting

is the failure to recall a memory due to missing stimuli or cues that were present at the time the memory was encoded.

ይሄ ደግሞምን መሰላችሁ "ሰው አንድ ነገር የሚረሳው ቀድሞ ነገሩን Encode ሲያረግ በዙሪያው የነበረውምልክት (Cue) አሁን ላይ ካሌለ ነው።" ቆይ በምሳሌ ላስረዳችሁ students would sometimes forget what they had studied before an exam. This occurs because of the examination room's environmental conditions are different to the room or place where learning occurred. Green area ያለበት ቦታ አጥንታችሁ ግን ከዚያ ስትሄዱ እዚያ ያጠናችሁት ነገር ሊጠፋባችሁ ይችላል፣ ለምን ከተባለ ከgreen areaው(Cue) ቦታ ስለሄዳችሁ።

ሌላ ምሳሌጫት(cue) እየቃማችሁ ያጠናችሁት ነገር ከጫቱ የራቃችሁ ዕለት የምትረሱት ከሆነ ይህ Cue Dependent Forgetting ይባላል። ይሄ ምሳሌ ለድሬ ተማሪዎች በደንብ ይገባችኋል
