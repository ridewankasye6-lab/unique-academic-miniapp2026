Complete Study Notes — Comprehensive Guide to Tenses

⏳ Tenses Overview

Tenses denote the time of action. They show when the work is done. They are:

  1. Present Tense
  2. Past Tense
  3. Future Tense

🌞 Present Tense

1. Simple Present Tense

It is used to denote scientific facts, universal truths and work done on daily basis.

⚙️ Structural Rules:
• Assertive: Sub + V1 + s/es + Object
• Negative: Sub + does not + V1 + s/es + Object
• Interrogative: Does + Sub + V1 + s/es + Object
• Interrogative Negative Assertive: Does + Sub + not + V1 + s/es + Object
💡 Examples:
• Assertive: She writes a letter.
• Negative: She does not write a letter.
• Interrogative: Does she write a letter?
• Interrogative Negative: Does she not write a letter?

2. Present Continuous Tense

It is used to express an action taking place at the time of speaking.

⚙️ Structural Rules:
• Assertive: Sub + is/am/are + V1 + ing + Object
• Negative: Sub + is/am/are + not + V1 + ing + Object
• Interrogative: Is/am/are + Sub + V1 + ing + Object
• Interrogative Negative: Is/am/are + Sub + not + V1 + ing + Object
💡 Examples:
• Assertive: She is writing a letter.
• Negative: She is not writing a letter.
• Interrogative: Is she writing a letter?
• Interrogative Negative: Is she not writing a letter?

3. Present Perfect Tense

It is used to show an action that started in the past and has just finished.

⚙️ Structural Rules:
• Assertive: Sub + has/have + V3 + Object
• Negative: Sub + has/have + not + V3 + Object
• Interrogative: Has/have + Sub + V3 + Object
• Interrogative Negative: Has/have + Sub + not + V3 + Object
💡 Examples:
• Assertive: She has written a letter.
• Negative: She has not written a letter.
• Interrogative: Has she written a letter?
• Interrogative Negative: Has she not written a letter?

4. Present Perfect Continuous Tense

This tense shows the action which started in the past and is still continuing.

⚙️ Structural Rules:
• Assertive: Sub + has/have + been + V1 + ing + Object
• Negative: Sub + has/have + not been + V1 + ing + Object
• Interrogative: Has/have + Sub + been + V1 + ing + Object
• Interrogative Negative: Has/have + Sub + not + been + V1 + ing + Object
💡 Examples:
• Assertive: She has been writing a letter.
• Negative: She has not been writing a letter.
• Interrogative: Has she been writing a letter?
• Interrogative Negative: Has she not been writing a letter?

📜 Past Tense

Tense symbolizes the ever moving, non-stop wheel of time which is forever busy gathering moments of future and throwing them into the dustbin of past.

1. Simple Past Tense

Used to indicate an action completed in the past. It often occurs with an adverb of time, but sometimes without. Also used for past habits.

⚙️ Structural Rules:
• Assertive: Subject + V2 + Object + (.)
• Negative: Subject + didn’t + V1 + Object + (.)
• Interrogative: Did + Subject + V1 + Object + (?)
• Interrogative Negative: Did + Subject + not + V1 + Object + (?)
💡 Examples:
• I played football when I was a child.
• Assertive: She wrote a letter.
• Negative: She didn’t write a letter.
• Interrogative: Did she write a letter?
• Interrogative Negative: Did she not write a letter?

2. Past Continuous Tense

Used to denote an action going on at some time in the past.

⚙️ Structural Rules:
• Assertive: Subject + was/were + V1 + ing + Object + (.)
• Negative: Subject + was/were + not + ing + Object + (.)
• Interrogative: Was/were + Subject + ing + Object + (?)
• Interrogative Negative: Was/were + Subject + not + ing + Object + (?)
💡 Examples:
• I was driving a car.
• Assertive: She was writing a letter.
• Negative: She was not writing a letter.
• Interrogative: Was she writing a letter?
• Interrogative Negative: Was she not writing a letter?

3. Past Perfect Tense

Used to describe an action completed before a certain moment in the past, usually a long time ago. If two actions happened in the past, past perfect is used to show the action that took place earlier.

⚙️ Structural Rules:
• Assertive: Subject + had + V3 + Object + (.)
• Negative: Subject + had + not + Object + (.)
• Interrogative: Had + Subject + V3 + Object + (?)
• Interrogative Negative: Had + Subject + not + V3 + Object + (?)
💡 Examples:
• The patient had died before the doctor came.
• Assertive: She had written a letter.
• Negative: She had not written a letter.
• Interrogative: Had she written a letter?
• Interrogative Negative: Had she not written a letter?

4. Past Perfect Continuous Tense

Used to denote an action that began before a certain point in the past and continued up to some time in past.

⚙️ Structural Rules:
• Assertive: Subject + had been + V1 + ing + Object + (.)
• Negative: Subject + had + not been + V1 + ing + Object + (.)
• Interrogative: Had + Subject + been + V1 + ing + Object + (?)
• Interrogative Negative: Had + Subject + not + been + V1 + ing + Object + (?)
💡 Examples:
• I had been learning English in this school for 20 days.
• Assertive: She had been writing a letter.
• Negative: She had not been writing a letter.
• Interrogative: Had she been writing a letter?
• Interrogative Negative: Had she not been writing a letter?

🚀 Future Tense

Time and tide wait for no man. So, a period of time following the moment of speaking or writing is called future tense.

📌 Usage Note for Shall/Will:
• In Future Tense, helping verb 'Shall' is used with 'I' and 'We'. Helping verb 'Will' is used with all others.
• When you are to make a commitment or warn someone or emphasize something, use of 'will/shall' is reversed. 'Will' is used with 'I' & 'We' and 'shall' is used with others.
• In general speaking there is hardly any difference between 'shall & will' and normally 'Will' is used with all.

1. Simple Future Tense

Tells us about an action which has not occurred yet and will occur after saying or in future.

⚙️ Structural Rules:
• Assertive: Subject + Will/Shall + Verb (1st form) + Object + (.)
• Negative: Subject + Will/Shall + Not + Verb (1st form) + Object + (.)
• Interrogative: Will/Shall + Subject + Verb (1st form) + Object + (?)
• Interrogative Negative: Will/Shall + Subject + Not + Verb (1st form) + Object + (?)
💡 Examples:
• Assertive: She will write a letter.
• Negative: She will not write a letter.
• Interrogative: Will she write a letter?
• Interrogative Negative: Will she not write a letter?

2. Future Continuous Tense

Used to express an ongoing or continued action in future. We use it to talk about something that will be in progress at or around a time in the future.

⚙️ Structural Rules:
• Assertive: Subject + Will/Shall + Be + Verb (1st form) + Ing + Object + (.)
• Negative: Subject + Will/Shall + Not + Be + Verb (1st form) + Ing + Object + (.)
• Interrogative: Will/Shall + Subject + Be + Verb (1st form) + Ing + Object + (?)
• Interrogative Negative: Will/Shall + Subject + Not + Be + Verb (1st form) + Ing + Object + (?)
💡 Examples:
• He will be distributing sweets in temple tomorrow at 12 o'clock.
• They will be staying for a week.
• Assertive: She will be writing a letter.
• Negative: She will not be writing a letter.
• Interrogative: Will she be writing a letter?
• Interrogative Negative: Will she not be writing a letter?

3. Future Perfect Tense

Used to express an action which will happen/occur in future and will be completed by a certain time in future.

⚙️ Structural Rules:
• Assertive: Subject + Will/Shall + Have + Verb (3rd form) + Object + (.)
• Negative: Subject + Will/Shall + Not + Have + Verb (3rd form) + Object + (.)
• Interrogative: Will/Shall + Subject + Have + Verb (3rd form) + Object + (?)
• Interrogative Negative: Will/Shall + Subject + Not + Have + Verb (3rd form) + Object + (?)
💡 Examples:
• They will have shifted the house by Sunday morning.
• Assertive: She will have written a letter.
• Negative: She will not have written a letter.
• Interrogative: Will she have written a letter?
• Interrogative Negative: Will she not have written a letter?

4. Future Perfect Continuous Tense

Used to talk about actions that will commence at a fix time in future and will continue for some time in future. Emphasizes the duration of an activity that will be in progress before another time or event in the future.

⚠️ Crucial Rule: If there is no time reference, then it is not a Future perfect continuous tense. Without continued time reference, such sentences are Future Continuous Tense.
⚙️ Structural Rules:
• Assertive: Subject + Will/Shall + Have been + Verb (1st form) + Ing + Object + (.)
• Negative: Subject + Will/Shall + Not + Have been + Verb (1st form) + Ing + Object + (.)
• Interrogative: Will/Shall + Subject + Have been + Verb (1st form) + Ing + Object + (?)
• Interrogative Negative: Will/Shall + Subject + Not + Have been + Verb (1st form) + Ing + Object + (?)
💡 Examples:
• This time tomorrow, I will be enjoying the cricket match in the stadium.
• Assertive: She will have been writing a letter.
• Negative: She will not have been writing a letter.
• Interrogative: Will she have been writing a letter?
• Interrogative Negative: Will she not have been writing a letter?

🎯 University Level Mixed Tenses Practice

Test your knowledge with these 10 advanced, mixed-tense examination questions. Answers are provided directly below each item.

  1. Question 1: By the time the supreme court judge ____________ (deliver) the final verdict tomorrow, the jury ____________ (deliberate) for over forty hours continuous.
    ✅ Answer: delivers | will have been deliberating
    Explanation: Time clause takes Simple Present ("delivers"), while the main clause requires Future Perfect Continuous to emphasize duration before a future point.
  2. Question 2: While the researchers ____________ (analyze) the empirical data last night, a system crash suddenly ____________ (wipe) out the unbacked server files.
    ✅ Answer: were analyzing | wiped
    Explanation: Past Continuous for an ongoing past action interrupted by a completed action in Simple Past.
  3. Question 3: Water ____________ (freeze) at 0 degrees Celsius under standard atmospheric pressure, regardless of geographic location.
    ✅ Answer: freezes
    Explanation: Simple Present Tense used to denote universal truths and scientific facts.
  4. Question 4: Professor Aberra ____________ (publish) three landmark studies on constitutional reform since he joined the university faculty in 2018.
    ✅ Answer: has published
    Explanation: Present Perfect Tense used for an action that began in the past and continues to have relevance in the present (marked by "since").
  5. Question 5: The defense attorney claimed that his client ____________ (leave) the country two days before the alleged incident ____________ (take) place.
    ✅ Answer: had left | took
    Explanation: Past Perfect Tense ("had left") denotes the earlier of two completed past actions.
  6. Question 6: At this precise moment, the parliamentarians ____________ (debate) the draft fiscal policy bill in the main assembly hall.
    ✅ Answer: are debating
    Explanation: Present Continuous Tense used for an action occurring right at the moment of speaking.
  7. Question 7: By next December, our academic platform ____________ (reach) over one hundred thousand active student users nationwide.
    ✅ Answer: will have reached
    Explanation: Future Perfect Tense used for an action that will be completed prior to a specified future deadline ("By next December").
  8. Question 8: Prior to her modern research presentation yesterday, the keynote speaker ____________ (rehearse) her theoretical framework for weeks.
    ✅ Answer: had been rehearsing
    Explanation: Past Perfect Continuous Tense highlights an ongoing activity in progress up to a specific past moment.
  9. Question 9: I strictly promise that I ____________ (submit) the finalized legal draft to your desk first thing tomorrow morning.
    ✅ Answer: will submit
    Explanation: Simple Future Tense using "will" expresses a strong personal commitment or promise.
  10. Question 10: Why ____________ you ____________ (look) so exhausted right now? — Because I ____________ (study) non-stop since dawn.
    ✅ Answer: do... look | have been studying
    Explanation: Simple Present state query paired with Present Perfect Continuous for an action started in the past whose continuous duration explains a present condition.
