📖 Lesson: Conditional Sentences (If-Clauses) for Beginners

🤔 What is a Conditional Sentence?

A conditional sentence tells us what happens (or might happen) if something else happens.

It often has two parts:

  1. If-clause (condition) → shows the “if” part
  2. Main clause (result) → shows the result or consequence
💡 Example:
If it rains, we will stay at home.
• “If it rains” = the condition
• “We will stay at home” = the result

There are 4 main types of Conditional Sentences:

Type Name Meaning Example
0 Zero Conditional Always true / Facts If you heat water to 100°C, it boils.
1 First Conditional Real and possible future If it rains, I will take an umbrella.
2 Second Conditional Unreal or imaginary present/future If I had a car, I would drive to work.
3 Third Conditional Unreal past (regret or imagination) If I had studied, I would have passed the test.

🔬 Type 0 – Zero Conditional

Meaning: We use it for facts, truths, or things that always happen.

⚙️ Structure:
If + Present Simple, Present Simple

🗣 Example Sentences:

  • • If you heat ice, it melts.
  • • If I drink coffee at night, I can’t sleep.
  • • Plants die if they don’t get water.
📌 Tip:
You can replace “if” with “when” because it’s always true:
→ When you heat ice, it melts.

🌤 Type 1 – First Conditional

Meaning: We use it for real or possible situations in the future.

⚙️ Structure:
If + Present Simple, will + Base Verb

🗣 Example Sentences:

  • • If it rains tomorrow, I will stay home.
  • • If I study hard, I will pass the exam.
  • • If you hurry, you will catch the bus.
📌 Tip:
Think of it as a real possibility.

💭 Type 2 – Second Conditional

Meaning: We use it for unreal or imaginary situations in the present or future.

⚙️ Structure:
If + Past Simple, would + Base Verb

🗣 Example Sentences:

  • • If I had wings, I would fly.
  • • If I won the lottery, I would buy a big house.
  • • If he were taller, he would play basketball.
📌 Tip:
We use “were” for all subjects (I/he/she/it).
→ “If I were you, I would study more.” (correct!)

🌧 Type 3 – Third Conditional

Meaning: We use it for unreal situations in the past — to express regret or imagine a different past.

⚙️ Structure:
If + Past Perfect, would have + Past Participle

🗣 Example Sentences:

  • • If I had studied, I would have passed the test.
  • • If they had left earlier, they would have caught the train.
  • • If we had known, we would have come.
📌 Tip:
Think: “It didn’t happen, but I wish it did.”

🎁 Bonus: Mixed Conditionals (Advanced – optional)

Sometimes we mix time frames, e.g.:

💡 Example:
• If I had studied (past), I would be a doctor now (present).

This is called a mixed conditional, but beginners can skip it for now.

📊 Summary Table

Type When We Use It Structure Example
Zero Facts / Truths If + Present, Present If you heat ice, it melts.
First Possible Future If + Present, will + Verb If it rains, I will stay home.
Second Unreal Present/Future If + Past, would + Verb If I had a car, I would drive.
Third Unreal Past If + Past Perfect, would have + Past Participle If I had studied, I would have passed.

📝 QUIZ – Conditional Sentences

Choose the correct answer or fill in the blanks.

Part A – Multiple Choice (1–10)

Choose the correct option.

  1. 1. If water reaches 0°C, it ______.
    a) freezes
    b) froze
    c) will freeze
    ✅ Answer: a) freezes
  2. 2. If it rains tomorrow, we ______ at home.
    a) stay
    b) stayed
    c) will stay
    ✅ Answer: c) will stay
  3. 3. If I ______ you, I would apologize.
    a) am
    b) were
    c) was
    ✅ Answer: b) were
  4. 4. If they had studied harder, they ______ the exam.
    a) will pass
    b) would pass
    c) would have passed
    ✅ Answer: c) would have passed
  5. 5. If you heat ice, it ______.
    a) melt
    b) melts
    c) melted
    ✅ Answer: b) melts
  6. 6. If she ______ earlier, she will catch the bus.
    a) leaves
    b) left
    c) had left
    ✅ Answer: a) leaves
  7. 7. If I won a million dollars, I ______ a new house.
    a) will buy
    b) would buy
    c) bought
    ✅ Answer: b) would buy
  8. 8. If I had known about the meeting, I ______.
    a) come
    b) would come
    c) would have come
    ✅ Answer: c) would have come
  9. 9. If the weather is nice, we ______ a picnic.
    a) will have
    b) would have
    c) have had
    ✅ Answer: a) will have
  10. 10. If I don’t eat breakfast, I ______ hungry.
    a) am
    b) was
    c) will be
    ✅ Answer: c) will be

Part B – Fill in the blanks (11–15)

  1. 11. If you ______ (study) more, you will pass the exam.
    ✅ Answer: study
  2. 12. Plants die if they ______ (not / get) enough water.
    ✅ Answer: don't get
  3. 13. If I ______ (be) you, I would call her.
    ✅ Answer: were
  4. 14. If we ______ (leave) earlier, we would have caught the bus.
    ✅ Answer: had left
  5. 15. If it ______ (rain), I will stay home.
    ✅ Answer: rains

Part C – Identify the Type (16–20)

Write Zero, First, Second, or Third.

  1. 16. If you mix red and blue, you get purple.
    ✅ Answer: Zero
  2. 17. If I had wings, I would fly.
    ✅ Answer: Second
  3. 18. If it rains tomorrow, we will stay home.
    ✅ Answer: First
  4. 19. If I had studied harder, I would have passed.
    ✅ Answer: Third
  5. 20. If you heat water, it boils.
    ✅ Answer: Zero
